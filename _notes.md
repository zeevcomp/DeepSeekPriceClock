**v1.6.0 — a thinner, prettier clock: only the expensive hours get color.**

### What's new
- ✨ **Cleaner, prettier face** — the thick blue ring is gone; the clock now has a slim, elegant **neutral frame** (three delicate hairlines)
- 🎯 **Color only for the expensive time** — instead of coloring the whole frame:
  - **Amber arcs on the dial mark the peak (full-price) hours**, converted to your local time (e.g. in Israel: 04–07 and 09–13; in New York: 21–24 and 02–06). On weekends no arcs appear — nothing is expensive
  - A **small dot at the current hour** turns amber only while a peak window is active; otherwise it stays neutral gray
- ⚙️ Verified across time zones: same UTC windows map correctly to Jerusalem (+180 min), New York (−240), China (+480), including arcs that cross midnight/noon

### Still included
- Analog clock by default; silky ~30 fps hands
- Live local time zone, Hebrew + English UI
- Current prices per 1M tokens (USD) for `deepseek-v4-flash`, `deepseek-v4-pro`, `deepseek-v4-flash-vision-exp`
- Automatic price updates from the official DeepSeek pricing page (every 30 min + on demand)
- Single portable `.exe` — 64-bit Windows 10/11, no install
